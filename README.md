## About the Project

The **Data Science Digital Library** is a web-based platform designed to provide students with easy access to Data Science laboratory experiments, learning modules, programming resources, and useful Data Science tools.

The platform organizes learning materials in one place, making it easier for students to explore experiments, understand concepts, and practice programming.

## Features

- **Digital Library** – Access Data Science learning materials and modules.
- **Laboratory Experiments** – Explore programming experiments and their outputs.
- **Data Science Tools** – Discover tools useful for Data Science and analytics.
- **Module Viewer** – View learning materials through the website.
- **Student Profile** – Access student-related information.
- **User-Friendly Interface** – Navigate through a clean and organized design.

## Run the Project Locally

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Python (if required by the backend)

### Steps

**1. Clone the repository**

```bash
git clone https://github.com/bapathisharanya28/DS-LAB-WEB.git
```

**2. Navigate to the project folder**

```bash
cd DS-LAB-WEB
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the frontend development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.

> **Note:** If the project uses a separate backend, configure and start it according to the dependencies and instructions in the `server` folder.
